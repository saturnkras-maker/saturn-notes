Агент не должен ждать, пока нажмут Enter

Цель доклада — превратить Claude Code из инструмента по запросу в «напарника», который сам замечает поломку и берётся за неё.

Докладчица Майя (Applied AI, Anthropic) открывает последний воркшоп первого дня Code with Claude. Опрос зала: многие запускали Claude Code по cron, но поддерживать эту обвязку понравилось одному человеку. В Anthropic испытали ту же боль и сделали функцию routines. План доклада: сложности проактивных агентов, что такое routines, внутренний пример с документацией, применение к своим процессам.

 Интерпретация CoS

Разница между «инструментом» и «напарником» — кто делает первый шаг. Пока первым пишет владелец, агент остаётся инструментом, сколько бы он ни умел.

05▶ 04:22до 05:27Что такое routines

Routine = промпт + репозитории + подключения + триггер

Routine — автоматизация, которая запускает удалённую сессию Claude Code; человек задаёт только промпт, репозитории, подключения и триггер, остальное делает Claude Code.

Два первых свойства: агенты всегда доступны — работают в управляемой облачной инфраструктуре, Anthropic берёт на себя хостинг, состояние сессии и вход в подключения, ноутбук можно закрыть. Триггеры настраиваются: расписание, нативные события GitHub или свои события через webhook, где данные события попадают в контекст.

 Интерпретация CoS

Четыре поля описания — хороший минимальный шаблон любого поручения агенту, даже без этой функции.

08▶ 07:04до 08:39Пример: документация

Routine заводится одной фразой через /schedule

Claude отвечает уточнениями: в какое время недели запускать и как сообщать о PR (например, в Slack). После ответов сам создаёт routine. Докладчица просит зал подумать, какие ежедневные задачи выиграли бы от расписания.

Качество: агент проверяет агента и человек в живой сессии

Второй способ — открыть живую сессию в вебе, задать вопрос посреди работы, повернуть агента; можно возобновить прошлую сессию и продолжить разговор.

Проверка после выкладки и доверие ступенями

Пример routine «проверка выкладки»: CD-конвейер после каждой выкладки отправляет POST на webhook routine.

Контекст — исходники сервиса и мониторинг (Datadog, Grafana); оповещение — Slack, почта или SMS (Twilio).
